# 🎂 3D生日蛋糕

一个 3D 生日蛋糕祝福网页（给元元❤），包含蛋糕、爱心动画和背景音乐。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 网页本体（单文件，直接打开或部署即可） |

## 使用方法

### 本地直接打开
双击 `index.html`，用浏览器打开即可（需要联网加载字体和 3D 引擎）。

### 部署到 GitHub Pages（免费）
1. 登录 GitHub，点右上角 `+` → **New repository**
2. 仓库名随意（如 `birthday-cake`），选 **Public**，勾选 Add a README file，点创建
3. 进入仓库 → **Add file** → **Upload files** → 把 `index.html` 拖进去 → **Commit changes**
4. 点 **Settings** → 左侧 **Pages** → Source 选 `Deploy from a branch` → Branch 选 `main`、文件夹 `/ (root)` → **Save**
5. 等 1～3 分钟，访问 `https://你的用户名.github.io/birthday-cake` 即可看到网页

## 提示
- 网页需要联网加载 three.js（3D 引擎）和字体，断网时显示不完整
- 若想个性化修改文字，用记事本打开 `index.html` 搜索页面文字直接改即可
